A USEFUL FIRST TEST

Follow one member’s journey.

  1. Sign in with learner / learn1234, or choose Create learner account. No activity or results are preloaded. If the learner tab is signed in as admin, sign out there; the admin tab uses a separate login.
  2. In the learner tab, open Get help and share a need.
  3. In the admin tab, refresh Member needs, respond, and mark it in progress.
  4. Refresh the learner tab to see that response. Try the next-step planner.
  5. Start a learning path and complete the before/after checks. All results start empty and reflect only the activity you save.
  6. Return to admin Home to see the saved result.
  7. In admin Mentors, create a profile and its login. Request that mentor as a learner, then assign or schedule the connection as admin.
  8. Sign out of the learner tab and sign in using your new mentor credentials. Check My mentees and update the assigned session. No message is sent automatically.
  9. In admin Settings, review AI model/key settings. No live API key is supplied; prepared guidance works without one.

What is connected in this preview?

Starting clean: no sample activity, events, results, funding, or messages are preloaded. The administrator, empty Test learner, courses, starter groups, and official resources are kept. No mentor login is preloaded.

Working locally: saved records, three login roles, courses, metrics, assigned mentor sessions, member needs, membership groups, messages, imports, exports, and reports.

Prepared guidance: admin Settings supports a model and an encrypted, write-only API key. Blank keeps a saved key; removing it enables any environment-key fallback. No live key is supplied, so the assistant labels prepared-guide mode. Email/text drafts can be queued, but local preview delivery is blocked. Meetings use external links; video calls are not hosted inside this app.

For review: use fictional information. Creating a mentor login or saving a meeting sends no invitation, email, or text. No real mentor has been contacted, grant submitted, or message sent. This preview is not the official TechWomenAZ service.
